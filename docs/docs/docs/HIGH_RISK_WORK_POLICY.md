## 1. 문서 목적

이 문서는 포항양극재공장 안전관리 플랫폼에서 고위험작업을 판정하고, 작업 전 사전검토부터 작업 종료까지 필요한 안전조치를 일관되게 관리하기 위한 기준을 정의한다.

고위험작업은 일반 위험성평가와 작업허가만으로 관리하지 않고 다음 절차를 추가 적용한다.

1. 고위험작업 해당 여부 판정
2. 운영부서·정비부서 합동 사전검토
3. 작업수행사·운영부서·정비부서 합동 위험성평가
4. 작업특성별 맞춤 체크리스트 작성
5. 필요한 경우 담당 임원 또는 실장 사전승인
6. 생명지킴이 배치
7. ILS 적용 여부 및 실시상태 확인
8. 안전작업허가
9. TBM 및 작업중지권 고지
10. 작업 중 주기별 안전조치 이행점검
11. 미흡사항 조치 및 재점검
12. 위험 발생 시 작업중지
13. 작업 종료 후 설비 복구
14. ILS 대상 작업의 잠금 해제 완료 확인
15. 허가서와 점검기록의 통합 보관

이 문서는 법령 위반 여부나 최신 법령 적합 여부를 자동 확정하기 위한 문서가 아니다.

이미지·발췌자료에 포함된 법령 조항, 수치, 예외사항은 원본 문서의 최신성과 적용범위를 확인한 후 운영에 반영한다.

## 2. 적용 원칙

### 2.1 작업유형과 고위험작업의 구분

작업유형과 고위험 특별관리 대상 여부는 별도로 관리한다.

예:

- 작업유형: 화기작업
- 고위험작업 해당 여부: 해당
- 고위험 분류: 화재·폭발 위험개소 작업
- 판정 사유: 인화성가스 존재 가능 장소의 화기작업

모든 화기·고소·전기·중량물 작업을 자동으로 같은 수준의 고위험작업으로 확정하지 않는다.

작업 장소, 높이, 전압, 물질, 장비, 작업방법 및 주변 조건을 함께 검토하여 판정한다.

### 2.2 기준과 실적의 분리

고위험작업 기준과 실제 작업기록을 분리한다.

#### 기준자료

- 고위험작업 판정조건
- 작업유형별 필수 위험요인
- 작업유형별 필수 안전대책
- 체크리스트 항목
- 점검 주체와 주기
- 작업중지 조건
- 예외조건

#### 실제 작업기록

- 해당 작업의 고위험 판정
- 위험성평가
- 맞춤 체크리스트
- 사전승인
- 생명지킴이
- ILS 상태
- 작업 중 점검
- 미흡사항과 조치
- 작업중지·재개
- 작업 종료
- ILS 해제 확인

### 2.3 자동 판정의 한계

시스템은 고위험작업 해당 가능성을 제안할 수 있으나 최종 판정은 권한 있는 담당자가 확인한다.

다음 항목은 시스템이 자동 확정하지 않는다.

- 법령 적용 여부
- 사내기준 예외 적용
- 고위험작업 최종 제외
- 작업허가 승인
- 작업중지 후 재개
- 작업완료
- 최신 법령 준수 여부

## 3. 고위험작업의 정의

고위험작업은 화기, 밀폐공간, 고부식성 유해화학물질 취급, 고위험 고소·중량물·전기작업 등 중대재해가 발생할 가능성이 높은 작업을 의미한다.

최소 관리대상은 다음과 같다.

- 화재·폭발 위험개소 작업
- 밀폐공간 작업
- 고부식성 강산·강염기 작업
- 고위험 고소작업
- 고위험 중량물·양중작업
- 고위험 전기작업

한 작업이 여러 고위험 분류에 동시에 해당할 수 있다.

예:

- 밀폐공간 내부 용접 → 밀폐공간 + 화재·폭발
- 고소 위치 배관 용접 → 고소 + 화재·폭발
- 전기설비 중량물 교체 → 전기 + 중량물
- 강산 배관 고소 정비 → 화학물질 + 고소

복합 고위험작업은 하나의 대표 유형만 남기지 않고 모든 해당 분류를 보존한다.

## 4. 공통 고위험작업 판정정보

| reasons | 판정 사유 |
| criteria | 적용한 기준 |

| reviewedBy | 검토자 |

- 미판정

## 5. 화재·폭발 위험개소 작업

### 5.1 고위험 판정 후보

다음 작업은 화재·폭발 고위험작업 해당 여부를 우선 검토한다.

- 인화성 액체 또는 증기가 존재하는 장소의 화기작업
- 인화성가스가 존재하거나 유입될 수 있는 장소의 화기작업
- 산소배관 직접 용접·용단 작업
- 가연성가스 배관·저장설비의 화기작업
- 산소 배관·저장설비의 화기작업
- 인화성 액체 배관·탱크의 화기작업
- 폭발위험 장소의 화기작업
- 밀폐공간 내부 화기작업
- 사내기준에서 고위험으로 지정한 공장동 내부 화기작업
- 화재·폭발 위험원과 일정 거리 이내에서 수행하는 화기작업

확보된 자료에는 직선거리 11m 기준이 표시되어 있으나, 정확한 적용대상과 최신 유효성을 확인한 후 시스템 기준값으로 확정한다.

### 5.2 확인해야 할 작업조건

- 화기작업 방식
- 용접·용단·연삭·가열 여부
- 실내·옥외 여부
- 밀폐공간 여부
- 인화성 액체·가스 존재 여부
- 산소설비 여부
- 배관·탱크 잔류물질 여부
- 주변·하부 가연물
- 개구부·틈새·하부층
- 가연성가스 측정 필요 여부
- 환기·국소배기
- 화재감시자
- 소화설비
- 불티방지포
- 작업 종료 후 잔불 확인

### 5.3 주요 필수 통제기능

- 화기작업 허가
- 가연물 제거·격리
- 가연성가스 측정
- 환기 또는 국소배기
- 불티 비산 방지
- 적합한 소화설비
- 화재감시자
- 전기용접기 안전조치
- 가스용접·용단 누설방지
- 역화방지
- 용기 전도방지
- 위험 특화 보호구
- 작업 종료 후 잔불 확인
- 비상대응 및 작업중지 기준

### 5.4 예외 처리

옥외·정비작업장 등 자료에 표시된 예외는 일반 화기작업 안전조치의 면제가 아니라 고위험 특별관리 대상의 예외일 수 있다.

예외 적용 시 다음을 기록한다.

- 적용한 예외 기준
- 작업 장소
- 주변 위험원
- 가연성가스 측정결과
- 검토자
- 승인자
- 예외 적용 사유

## 6. 밀폐공간 작업

### 6.1 고위험 판정 후보

다음 작업은 밀폐공간 고위험작업으로 우선 검토한다.

- 산소결핍 위험이 있는 장소의 작업
- 유해가스가 존재할 수 있는 장소의 작업
- 유해가스가 유입·발생할 수 있는 장소의 작업
- 출입이 제한되고 자연환기가 불충분한 장소의 작업
- 탱크·맨홀·로 내부 등 사내 밀폐공간으로 관리되는 장소의 작업
- 불활성가스가 유입될 수 있는 설비 내부 작업
- 밀폐공간 내부 화기작업

### 6.2 주요 필수 통제기능

- 밀폐공간 해당 여부 사전조사
- 유입·발생 가능한 가스 확인
- 유입원 차단
- 최초 산소·유해가스 다점 측정
- 적정공기 판정
- 강제환기
- 작업 중 1시간마다 공식 측정
- 현장조건에 따른 측정주기 단축
- 작업자 휴대용 검지기 연속측정
- 외부 감시인
- 출입통제·출입기록
- 통신수단
- 대피·구조장비
- 비상연락 및 구조계획
- 특별안전교육 및 구조훈련
- 호흡용 보호구
- 작업허가서 출입구 게시
- 경보 발생 시 즉시 대피
- 재진입 전 재측정

### 6.3 단순점검 예외

확보된 자료에는 일정 시간 이내의 단순점검 예외 문구가 있다.

이 예외는 다음과 같이 처리한다.

- 고위험 특별관리 대상 제외 가능성만 검토
- 밀폐공간 해당 여부는 별도 유지
- 산소·유해가스 측정 등 기본조치 면제 여부를 자동 판단하지 않음
- 출입·감시·비상대응 필요성을 별도 확인
- 예외 적용 근거와 승인자 기록

## 7. 고부식성 강산·강염기 작업

### 7.1 고위험 판정 후보

다음 작업은 고부식성 화학물질 고위험작업으로 우선 검토한다.

- 강산 배관 수리
- 강산 탱크 수리
- 강염기 배관 수리
- 강염기 탱크 수리
- 고부식성 물질이 잔류할 수 있는 설비 해체
- 누출·비산 가능성이 있는 플랜지·밸브·배관 작업
- 잔류압력이 존재할 수 있는 설비 작업

예시 물질:

- 황산 등 강산
- 수산화나트륨 등 강염기

물질별 적용 여부는 MSDS와 사내기준을 확인한다.

### 7.2 주요 필수 통제기능

- 물질명·농도 확인
- MSDS 확인
- 작업공정별 관리요령
- 작업자 교육
- 경고표지
- 유입원 차단
- ILS 적용·완료 확인
- 잔류압력 제거
- 드레인·세척
- 잔류물 확인
- 누출·비산 방지
- 환기·국소배기
- 작업구역 통제
- 비상세안·샤워
- 누출 방제장비
- 물질별 적합 보호구
- 누출물 회수·폐기
- 응급조치
- 작업 종료 후 오염 제거

### 7.3 물질별 적용 원칙

다음 조치를 모든 물질에 공통 적용하지 않는다.

- 물걸레 청소
- 물을 이용한 세척
- 특정 중화제
- 일반 진공청소기 사용
- 방진마스크
- 방독마스크

물질별 MSDS, 수분반응성, 물리적 형태 및 누출대응 절차를 확인한 후 적용한다.

### 7.4 예외 처리

시험·분석용 시약, 펌프 교체, 탱크 충전 등 자료에 표시된 예외는 고위험 특별관리 예외일 수 있다.

예외 적용 여부와 관계없이 일반 위험성평가와 기본 안전조치는 수행한다.

## 8. 고위험 고소작업

### 8.1 고위험 판정 후보

다음 작업은 고위험 고소작업으로 우선 검토한다.

- 5m 이상 지붕·벽체·철골 작업
- 고정식 안전난간대 또는 작업대가 없는 장소의 작업
- 가설·임시 떨어짐 방지시설에 의존하는 작업
- 비계 설치·해체 작업
- 달비계 작업
- 작업자가 고정식 난간대 또는 작업대를 이탈하는 작업
- 개구부 주변 작업
- 떨어질 경우 중대한 결과가 예상되는 작업

### 8.2 주요 필수 통제기능

- 작업높이 확인
- 적합한 작업장비 선정
- 작업발판
- 안전난간
- 개구부 방호
- 전도 방지
- 미끄럼 방지
- 아웃트리거
- 바퀴 제동
- 안전대 부착설비
- 안전대·안전블록
- 낙하물 방지
- 하부 출입통제
- 적재하중 관리
- 장비 상태점검
- 자재·공구 운반방법
- 기상·조도 확인
- 구조·비상대응

### 8.3 장비별 구분

고소작업은 다음 세부유형을 구분한다.

- 이동식 사다리
- 말비계
- 이동식 비계
- 고정식 수직사다리
- 고소작업대
- 고정 작업발판
- 개구부
- 지붕
- 비계 설치·해체
- 달비계

### 8.4 예외 처리

## 11. 복합 고위험작업

한 작업이 둘 이상의 고위험 분류에 해당하면 모든 분류를 저장한다.

예:

| 작업 | 고위험 분류 |
|---|---|
| 밀폐공간 내부 용접 | 밀폐공간, 화재·폭발 |
| 고소 위치 배관 용접 | 고소, 화재·폭발 |
| 강산 배관 고소 보수 | 화학물질, 고소 |
| 전기설비 중량물 교체 | 전기, 중량물 |
| 밀폐공간 내 전기정비 | 밀폐공간, 전기 |

복합작업에서는 다음 원칙을 적용한다.

- 한 개 대표 유형으로 축소하지 않음
- 유형별 위험요인 모두 검토
- 유형별 필수대책 모두 검토
- 중복 대책은 통합하되 출처 유지
- 서로 충돌하는 대책은 별도 검토
- 맞춤 체크리스트에 모든 해당 유형 반영
- 사전승인 범위에 복합위험 명시
- TBM에서 복합위험을 구분하여 안내

## 21. 고위험작업 TBM

### 21.1 실시 원칙

고위험작업은 최종 작업허가가 완료된 후 작업 시작 전에 TBM을 실시한다.

TBM은 작업계획서, 위험성평가, 안전작업허가서 및 맞춤 체크리스트를 근거로 실시한다.

TBM에서는 다음 사항을 확인하고 작업자에게 전달한다.

- 작업명과 작업범위
- 작업장소
- 작업단계
- 주요 위험요인
- 예상 사고시나리오
- 적용 안전대책
- 조치 예정자
- 작업 중 확인방법
- 작업중지 조건
- 비상조치
- ILS 상태
- 고위험작업 사전승인 조건
- 작업중지권
- 필요한 조건부 별지

### 21.2 위험성평가 연계

TBM에는 위험성평가에서 최종 선택된 정보를 위험요인별로 전달한다.

각 항목에는 다음 정보가 포함되어야 한다.

- riskItemId
- 위험요인
- 사고시나리오
- 안전대책
- 조치 예정자
- 현장 확인방법
- 작업중지 조건
- 출처 riskId
- 출처 jsaId
- 자동 채움 여부

위험요인과 안전대책의 연결관계를 유지한다.

다음과 같은 단순 전송은 지양한다.

- 위험요인: 위험성평가에서 도출
- 대책: 대책 문자열

### 21.3 ILS 확인

TBM은 기존 ILS 시스템의 상세 잠금정보를 입력하거나 수정하지 않는다.

안전작업허가서에서 확인한 다음 정보를 읽기 전용으로 표시한다.

- ILS 적용 여부
- ILS 완료 상태
- ILS 참조번호
- 기계설비 ILS 상태
- 전기설비 ILS 상태
- GIB 번호
- 허가 전 확인자
- 확인 시각

ILS 대상인데 완료상태가 확인되지 않으면 TBM 완료와 작업 시작을 제한한다.

TBM 참석자는 다음 사항을 확인한다.

- ILS 상태를 임의로 변경하지 않음
- 잠금장치를 임의로 해제하지 않음
- 에너지원 바이패스를 하지 않음
- 설비를 임의로 조작하지 않음
- 작업조건이 변경되면 즉시 작업을 중지하고 보고함

### 21.4 참석자 안전퀴즈 확인

고위험작업에 참여하는 작업자는 유효한 안전퀴즈 합격 기록이 있어야 한다.

TBM 참석자별로 다음을 확인한다.

- 작업자 식별값
- 이름
- 소속
- 안전퀴즈 합격 여부
- 응시일
- 유효기간
- 퀴즈 버전
- 검증 결과

다음 대상자는 작업 참여를 제한한다.

- 미응시자
- 불합격자
- 유효기간 만료자
- 신원 불일치자
- 소속 불일치자

안전퀴즈 결과와 관계없이 위험 신고와 작업중지 요청은 가능해야 한다.

### 21.5 작업중지권 고지

TBM에서는 작업자에게 다음 내용을 안내한다.

- 급박한 위험이 있으면 작업을 중지하고 대피할 수 있음
- 위험상황을 관리감독자에게 보고해야 함
- 필요한 안전조치가 완료된 후 작업을 재개함
- 합리적인 작업중지권 행사에 불리한 처우를 하지 않음
- 작업중지 요청 방법
- 비상연락 방법

TBM에는 다음 확인정보를 저장한다.

- 고지 문구 버전
- 법적 근거
- 고지 시각
- 참여자 명단
- 참여자 확인
- 대표자 이름
- 대표자 서명

법령 문구는 최신성 검토 후 사용한다.

### 21.6 TBM 완료 조건

다음 조건을 모두 충족해야 TBM을 완료할 수 있다.

- 최종 작업허가 완료
- 고위험 사전승인 완료
- 위험성평가 완료
- 맞춤 체크리스트 준비
- ILS 대상 작업의 완료상태 확인
- 작업자 안전퀴즈 합격 확인
- 위험요인·대책 전달
- 조치 예정자 지정
- 작업중지 조건 전달
- 작업중지권 고지
- 참석자 확인·서명
- 필요한 별지 작성

## 22. 고위험작업 점검 운영

### 22.1 모든 허가작업의 기본 이행상태 확인

고위험작업도 모든 허가작업에 적용되는 작업 시작 후 3시간 이내 안전 이행상태 확인 대상이다.

기본 확인은 작업수행사 관리감독자가 수행한다.

고위험작업의 생명지킴이 및 부서별 주기점검은 이 기본 확인에 추가하여 실시한다.

두 점검은 다음 목적을 가진다.

- 3시간 이내 기본 확인: 허가조건과 안전대책 전반의 초기 이행상태 확인
- 고위험 주기점검: 고위험작업의 필수 통제수단이 작업 종료까지 유지되는지 반복 확인

동일한 점검을 중복 인정할 수 있는지는 사내 운영기준에 따라 결정하고 근거를 기록한다.

### 22.2 작업 중 점검 목적

작업 중 점검은 허가 시 확인한 안전조치가 작업 종료까지 유지되는지 확인하기 위해 실시한다.

점검 결과는 허가서와 연결하여 보관한다.

### 22.3 점검 주체와 주기

현재 확보된 기준에 따른 점검 주체와 주기는 다음과 같다.

| 점검 주체 | 점검 주기 |
|---|---|
| 전담 생명지킴이 | 2시간마다 |
| 정비부서 담당자 | 오전·오후 각 1회 |
| 운영부서 관리감독자 | 오전·오후 각 1회 |
| 안전환경부서 | 오전·오후 각 1회 |

점검 주기는 작업시간과 작업조건을 고려해 예정시간을 생성한다.

실제 점검시각과 예정시각을 모두 기록한다.

### 22.4 대리점검

점검 주체가 부재하거나 수행할 수 없는 경우 사내기준에 따라 대리인을 지정할 수 있다.

대리점검 시 다음을 기록한다.

- 원 점검자
- 원 점검자 소속·역할
- 대리점검자
- 대리점검자 소속·역할
- 위임 사유
- 위임자
- 위임 시각
- 적용 점검회차

생명지킴이의 대리 가능 여부는 사내기준에 따른다.

현재 확보된 자료에서는 생명지킴이를 제외한 점검 주체의 대리 지정 가능성이 확인되므로, 생명지킴이는 임의로 대체하지 않는다.

### 22.5 점검기록

각 점검기록에는 다음 정보가 필요하다.

- inspectionNo
- permitNo
- riskId
- tbmNo
- 고위험작업 분류
- 점검표 유형
- 예정 점검시각
- 실제 점검시각
- 점검 주체
- 점검자
- 대리점검 여부
- 대리인 정보
- 항목별 판정
- 미흡사항
- 즉시조치
- 작업중지 여부
- 재점검 결과
- 특이사항
- 감사 필드

## 23. 점검 판정과 처리

### 23.1 판정값

종이 체크리스트와의 호환을 위해 다음 값을 사용한다.

- ○: 양호
- ×: 미흡
- -: 해당 없음

플랫폼 내부에서 보완 상태가 필요한 경우 별도 조치상태로 관리한다.

- 조치불필요
- 즉시조치
- 조치중
- 재점검대기
- 재점검완료

### 23.2 양호

양호 판정 시 다음을 기록한다.

- 점검자
- 점검시각
- 확인결과
- 필요 시 확인 의견

작업은 계속할 수 있다.

### 23.3 미흡

미흡 판정 시 다음을 기록한다.

- 미흡 항목
- 미흡 내용
- 발견 시각
- 발견자
- 위험의 심각성
- 즉시조치
- 조치 담당자
- 조치 예정시각
- 작업중지 여부
- 재점검 필요 여부

다음에 해당하면 작업중지 절차로 연결한다.

- 생명 또는 신체에 중대한 위험이 있음
- 필수 안전대책이 이행되지 않음
- 허가조건이 유지되지 않음
- ILS 상태가 유효하지 않음
- 산소·유해가스 기준을 벗어남
- 중대한 장비 이상이 있음
- 작업계획과 실제 작업이 다름
- 새로운 고위험 조건이 발생함

### 23.4 해당 없음

해당 없음 판정에는 사유를 기록한다.

다음 항목은 특별한 근거 없이 해당 없음으로 처리하지 않는다.

- 작업유형별 필수 안전조치
- 고위험 사전승인 조건
- ILS 적용 작업의 ILS 완료 확인
- 밀폐공간의 필수 측정
- 필수 감시인·신호수·작업지휘자
- 필수 방호장치
- 필수 보호구
- 작업중지 조건

## 30. 작업중지권 행사

### 30.1 작업중지 요청

작업자는 급박한 위험 또는 안전조치 미흡을 확인하면 작업을 중지하고 대피한 후 보고할 수 있다.

작업중지 요청은 다음 정보와 연결한다.

- emergencyNo
- permitNo
- workId
- riskId
- tbmNo
- 작업명
- 작업장소
- 발견 시각
- 작업중지 시각
- 위험요인
- 예상 사고유형
- 안전조치 미흡내용
- 즉시조치
- 요청자
- 요청자 소속
- 서명 또는 확인

안전퀴즈 합격 여부를 작업중지 요청 조건으로 사용하지 않는다.

### 30.2 작업중지 시 자동 처리

작업중지 요청이 접수되면 다음 처리를 수행한다.

- 긴급조치 기록 저장
- 작업허가 상태를 `작업중지`로 변경
- 작업DB 상태를 `작업중지`로 변경
- 관련 TBM에 emergencyNo 연결
- 위험성평가를 `재검토필요`로 표시
- 대시보드에 작업중지 상태 표시
- 필요 시 관리자 긴급 알림

기존 위험성평가와 TBM 원본을 자동으로 덮어쓰지 않는다.

### 30.3 불이익 금지

작업중지권 고지에는 합리적인 사유로 작업을 중지한 근로자에게 불리한 처우를 하지 않는다는 취지를 포함한다.

법령 문구는 최신성 검토와 담당부서 확인 후 사용한다.

## 35. 작업 종료 시 ILS 해제 확인

### 35.1 역할

실제 잠금 해제는 기존 ILS 시스템과 사내 ILS 절차에 따라 수행한다.

안전관리 플랫폼은 잠금 해제를 직접 수행하지 않고 해제 완료 사실을 확인·기록한다.

### 35.2 해제 전 확인

- 관련 부서 종료 통보

### 35.3 해제 완료 확인정보

- ILS 적용 여부
- 기존 ILS 시스템 참조번호
- 해제 상태
- 개인잠금 해제 확인
- 해제 확인자
- 해제 확인시각
- 대상 설비
- 방호장치 복구
- 설비운영부서 인계
- 재가동 승인
- 비고

### 35.4 확인 문구

> 작업자 전원 철수, 공구·자재 제거 및 설비 복구를 확인한 후 기존 ILS 시스템의 절차에 따라 잠금 해제가 완료되었음을 확인하였습니다.

### 35.5 작업완료 차단

다음 조건에서는 최종 작업완료로 전환하지 않는다.

- 작업자 철수 미확인

## 42. 완료 기준

고위험작업 운영 기능은 다음 조건을 모두 만족할 때 완료로 판단한다.

- 작업유형과 고위험 여부가 분리됨
- 복수 고위험 분류를 저장할 수 있음
- 판정 사유와 적용 기준이 기록됨
- 예외 적용 근거와 승인자가 기록됨
- 합동 위험성평가를 관리할 수 있음
- 맞춤 체크리스트가 위험성평가와 연결됨
- 사전승인 완료 전 허가가 차단됨
- 안전퀴즈 미합격자의 작업 참여가 제한됨
- ILS 완료 확인 전 허가가 차단됨
- TBM에 위험·대책·조치자가 연결됨
- 작업중지권이 사전 고지됨
- 주체·주기별 작업 중 점검이 기록됨
- 미흡사항의 최초 판정과 조치·재점검 이력이 보존됨
- 중대위험 발생 시 작업중지로 연결됨
- 재개 전 재평가·허가 확인·재TBM을 수행함
- 작업 종료 시 철수·복구를 확인함
- ILS 해제 완료 전 최종 작업완료가 제한됨
- 관련 문서를 permitNo로 통합 조회할 수 있음
- 개인정보와 내부정보가 공개 저장소에 노출되지 않음

## 44. 최종 원칙

고위험작업은 위험성평가서 한 장 또는 체크리스트 한 장으로 완료되지 않는다.

다음 전체 과정이 하나의 안전관리 절차로 연결되어야 한다.

> 고위험 판정 → 합동 사전검토 → 위험성평가 → 맞춤 체크리스트 → 사전승인 → 허가 전 ILS 확인 → 안전작업허가 → TBM → 작업 중 점검 → 작업중지·개선조치 → 재평가·재TBM → 작업 종료 → ILS 해제 확인 → 설비 인계 → 통합 보관

JSA_DB와 AI는 위험과 대책의 후보를 제공하고 누락을 확인하는 보조수단으로 사용한다.

최종 판정, 작업허가, 작업중지 후 재개, ILS 확인 및 작업완료는 권한 있는 사람이 현장조건을 확인한 후 결정한다.
