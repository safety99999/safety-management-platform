JSA DB 관리자 v2

- 템플릿 / 전체 DB / 업로드 양식은 모두 동일한 17열 구조입니다.
- 업로드는 엑셀 파일 선택 또는 엑셀 복사 후 붙여넣기 둘 다 가능합니다.
- Firestore 저장 시 필요한 관리값(jsaId, rowNo, version, 상태값)은 내부에서 자동 생성됩니다.
- 컬렉션명은 jsaDatabase 입니다.
⚠️ v2 주요 변경사항:
1. 위험도 컬럼 추가 (저위험/중위험/고위험/매우고위험/판정불가)
2. 통제 적정성 값 통일 (X → × 곱셈기호)
3. 자동 검증 강화

📥 다운로드

템플릿에는 17개 컬럼이 포함되어 있습니다.
전체 DB 다운로드는 Firestore의 jsaDatabase 컬렉션 전체를 조회합니다.
