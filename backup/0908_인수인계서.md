3. 상세 작업 이력
3-1. 대시보드 오늘 작업 데이터 갱신
문제
대시보드 홈에 오늘 작업이 8건만 표시됨 (실제 17건 존재)
정적 JSON 배포 이후 데이터 반영 안 됨
원인
Firestore에는 17건 저장되었으나, GitHub 정적 JSON은 이전 8건 스냅샷 상태
관리자 수동 배포 미실시로 사용자 화면 미갱신
조치
관리자 페이지 → 작업DB 재저장 → Firestore 반영
정적 JSON 재생성 → GitHub 자동 배포
db-manifest.json SHA-256 재계산 → 검증 통과
결과
오늘 작업 17건 정상 표시
위험성평가 DB 519건 정보 무결성 유지
3-2. GitHub 자동 배포 시스템 구축
배경
관리자가 데이터를 저장할 때마다 수동으로 GitHub 파일을 편집하는 것이 비효율적
배포 누락 시 사용자 화면에 오래된 데이터 표시
구현 내용
파일: 안전관리플랫폼_대시보드_V6_.html (관리자 설정 페이지)

주요 개선점:

수동 편집으로 인한 실수 방지

위험성평가 DB 정보(riskAssessmentDB) 자동 보존
3-3. manifest / JSON 필드명 표준화
문제 발견
정적 JSON 배포 후 화면에 데이터 미반영
콘솔 오류: data가 undefined
원인
파일	이전 필드명	실제 코드가 기대하는 필드명
db-manifest.json	path	filename
work-database.test.json	workHistory	data
조치
db-manifest.json 스키마 변경: path → filename
work-database.test.json 최상위 필드 변경: workHistory → data
GitHub 자동 배포 스크립트도 새 스키마로 통일
3-4. 테스터 자동채움 라이브러리 신규 개발
배경
TBM 페이지에는 이미 테스터 자동채움 기능 존재
위험성평가/허가서에도 동일 기능 필요 (테스트 효율화)
구현 방식: 옵션 C (공통 라이브러리 + 페이지별 커스터마이징)
신규 파일: assets/js/tester-autofill.js (v1.0.0)

핵심 기능:

자동 실행: 페이지 로드 후 300ms 뒤 자동 발동 (테스터 세션만)
비파괴적: 이미 값이 있는 필드는 건드리지 않음 (fillIfBlank)
필드 타입 자동 감지:
id, name, placeholder, label 텍스트 분석
정규식 패턴 매칭으로 이름/조직/연락처/작업/위험 등 자동 분류
input 타입별 처리:
date → 오늘 날짜
datetime-local → 현재 일시
email → test@test.co.kr
tel → 010-0000-0000
number → 인원 관련 3, 그 외 1
select 자동 선택: 첫 번째 유효 옵션
서명 캔버스 자동 렌더링: .sig-canvas 자동 감지 후 "TEST 서명" 텍스트 그리기
라디오/체크박스: 필수 항목 자동 처리
토글 버튼 (밀폐공간 등): "아니오" 안전 기본값 선택
시각적 표시:
채워진 필드에 초록색 그라디언트 배경

        │
        ├─ ① 오늘 작업목록
        │     · 작업관리대장 workId 보유
        │     · 오늘 작업만 표시
        │     · 위험성평가 완료 상태 표시
        │
        │     ├─ 위험성평가 완료
        │     │     → workId + riskId로 허가서 작성
        │     │
        │     └─ 위험성평가 미완료
        │           → 위험성평가 먼저 작성
        │
        └─ ② 신규평가 목록
              · 관리대장 외 평가
              · workId가 없는 평가
              · 평가완료 상태만 표시
              · riskId로 허가서 작성
진입 원칙
URL 조건	처리
workId + riskId	해당 평가를 연결해 허가서 1단계 진입
riskId만 있음	해당 신규평가를 연결해 1단계 진입
workId만 있음	같은 workId의 최신 완료 평가 연결
식별자 없음	사용자가 시작 목록에서 직접 선택
작업명만 유사	자동 연결 금지

21.10 대시보드 상세보기 진행 흐름
기본 작업카드는 단순하게 유지하고, 상세보기에서 다음 8단계를 표시합니다.

작업 진행 현황

① 위험성평가
② 안전정보 제공
③ 수급인 안전확인·퀴즈
④ 안전작업허가 신청
⑤ 허가자 승인
⑥ TBM
⑦ 작업 진행·점검
⑧ 작업 종료
표시 상태:

✅ 완료
▶ 진행 가능
⏳ 진행 중·대기
🔒 선행조건 미완료
⚠️ 보완 필요
🛑 작업중지
예시:

① 위험성평가       ✅ 완료
② 안전정보 제공    ✅ 발행
③ 수급인 확인      ⏳ 서명 대기
④ 작업허가         🔒 잠김
⑤ 허가승인         ─ 미진행
⑥ TBM              ─ 미진행
⑦ 작업진행         ─ 대기
⑧ 작업종료         ─ 대기
